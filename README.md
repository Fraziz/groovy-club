# GROOVY CLUB — Vintage Street Formal

> **GOOD VIBES. BETTER DAYS.**  
> *“Vintage character. Relaxed silhouettes. Everyday confidence.”*

An editorial digital flagship for **GROOVY CLUB**, presenting our design language: **Vintage Street Formal**—clothing recognized through fit, feel, silhouette, and construction.

---

## 🏛 Brand Architecture & Philosophy

- **Brand:** GROOVY CLUB
- **Tagline:** GOOD VIBES. BETTER DAYS.
- **Design Language:** Vintage Street Formal
  - Substantial garments starting at 260 GSM compact combed cotton.
  - Relaxed, slightly boxy silhouettes with controlled dropped shoulders.
  - Refined single-pleat tailoring and considered waistline architecture.
  - Warm earth tones, nostalgic character, and matte finishes.
  - Intentional, quiet branding and our signature **Groovy Curve** ergonomic seam detail.

---

## 🎨 Signature Palette & System Tokens

- **Signature Print Color:** `#CEA370` (Golden Camel / Amber Ochre)
  - Used for selected buttons, typography highlights, active states, and screen prints.
- **Warm Ivory:** `#F5F1E8` (Main editorial canvas)
- **Charcoal:** `#24221F` (Sartorial contrast & primary typography)
- **Soft Taupe:** `#DDD2C2` (Garment neutral & card tone)
- **Deep Espresso:** `#352A22` (Rich accent & community section)
- **Typography:** **Syne** (Bold characterful display) + **Plus Jakarta Sans** (Clean editorial body) + **Space Grotesk** (Sartorial specs)

---

## 👕 Collection & Garment Lineup

1. **Signature Tee (Core Piece)**
   - 260 GSM compact combed cotton.
   - 1.25" thick structured 1x1 crewneck collar.
   - Relaxed boxy drape with controlled dropped shoulders.
   - Matte water-based screen printing in signature `#CEA370`.
2. **Heritage Trouser**
   - Relaxed straight fit with a sharp single forward pleat.
   - 340 GSM wool-cotton blend with side buckle adjusters.
3. **Club Trouser**
   - Wider silhouette featuring the signature Groovy Curve front coin pocket.
4. **Evening Trouser**
   - High-twist midnight charcoal worsted wool gabardine with double reverse pleats.
5. **Weekend Trouser**
   - Relaxed waistband with concealed drawstring and easy drape.
6. **Signature Pinstripe**
   - Vintage tailoring with whisper-subtle tonal micro-stripe woven with `#CEA370` threads.

## 🚀 Local Development

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
